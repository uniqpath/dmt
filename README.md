[[[ [DMT SYSTEM](https://dmt-system.com/) ]]] is a framework for creating powerful decentralized realtime apps.

## DMT SYSTEM 1.0 → 2.0

This repo is a flawed proof of concept (v1) which works perfectly for design surface it was meant for. Since then DMT SYSTEM 2.0 is being developed which fixes many known vulnerabilities and greatly expands what the system can do. The entire user experience is on another level.

We are roughly at v1.5 currently. No yet sure how or when will v2.0 be available for general use. Open source is strange and often not properly rewarded. One often drowns in unpaid work where people just demand without contributing. So in addition to further technical improvements and modernization this part needs to be figured out if the project is ever going to be available for general hacker use.
I (David) personally believe that this is a great value add for the world but it takes further immense work on top of what was already done. Will have to decide at some point if it is worth a try to build a self-sustaining organisation with more people helping with support. More people means income is needed, otherwise the project falls apart. For now I'm incredibly happy where things are and these are just open questions for later.

When we started ~10 years ago it was jokingly said that this will be one of the best project in the history of computing. And now it actually is. It is a special kind of project with attention to detail and covering all aspects with best possible compromises. It worked out with addition of capable A.I. coding. Mathematical structure was right from the beginning and it needed concentrated multi-month guided push through most powerful A.I. models to bring the original plan to light with limited human resources.

## What

In short - it is a local-first (but entirely Internet enabled) life assistant which utilizes a network of sovereign personal devices to serve user-friendly distributed apps to control one's surroundings, get updates from the world and overal be faster and more organized with less friction with tasks that can be automated and monitored. System enables everything around you to just work better, one of notable things is home automation but certainly not the only one.

Barrier to entry is some hacker's knowledge — it is a tool for capable enthusiasts — developed and tested over 10 years. Almost impossible to develop from scratch or if it is the effort it would take should not be underestimated. Devil is in the details (and design choices)! It is truly amazing how it worked out. Hopefuly this does not sound too grandiose, there is a thin line between judging peoples' true happines and pride in having created something uncertain which turned out to just work.

Honestly I'm leaning towards keeping DMT 2.0 private not because of arrogance but also because properly promoting and explaining the entire system would take a heroic effort. It is more fear than arrogance. We don't do things half-assed here so we don't even start with marketing. I'm an engineer (and a tiny bit of a scientist) and don't want to deal with that really. Someone else should do it and they need to get paid. So this is an enourmous chicken and egg problem which is also kind of sad if indeed v2.0 is not more broadly distributed. Once we start in this direction there is no going back so it is better not to start at the moment.

I value potential benefit for the world in $42 to $69 x 10<sup>6</sup> range and it is mathematically (again) possible to reach / capture this but it's just hard and I'm not in a big mood for it currently. When we are at v2.0 this might change.
